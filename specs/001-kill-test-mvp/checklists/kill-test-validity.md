# Kill-Test Validity Checklist: Kill-Test MVP for Calibrated Multi-View Body-Measurement Uncertainty

**Purpose**: Unit tests for the requirements that make the kill verdict scientifically valid and reproducible: split integrity and leakage, calibration correctness, a verdict computed from saved outputs, and determinism. Each item asks whether the requirement is written well enough, not whether the code works.
**Created**: 2026-10-07
**Feature**: [spec.md](../spec.md); design in [plan.md](../plan.md), [research.md](../research.md), [data-model.md](../data-model.md)

**Note**: This checklist is generated by the `/speckit-checklist` command based on feature context and requirements. Depth: standard. Audience: the reviewer of the spec and plan before implementation and again before the full run. Focus chosen by the orchestrator: scientific validity and reproducibility of the kill test.

## Split Integrity and Leakage

- [ ] CHK001 Are the training, calibration, and test sets required to be disjoint by body identity rather than by image, so that the four views of one body never straddle splits? [Completeness, Spec §FR-010, §Key Entities Data Split]
- [ ] CHK002 Is the reuse of calibration and test bodies across cells (different view subsets and noise draws of the same bodies) stated as acceptable for per-cell exchangeability, with the reason? [Clarity, Spec §Assumptions "Data split", §FR-010]
- [ ] CHK003 Are requirements defined for the pose source so that one motion-capture frame reused by several bodies cannot create a leak between splits? [Gap, Spec §FR-001]
- [ ] CHK004 Is model selection (choice of epochs, checkpoints, or hyperparameters) on the calibration or test split prohibited explicitly? [Gap, Spec §FR-009, §FR-010]
- [ ] CHK005 Is "held-out" defined for the real-image datasets, given that no training touches BodyM or SSP-3D and the calibration quantiles come from synthetic bodies? [Clarity, Spec §FR-017, §FR-018, §FR-020]

## Calibration Correctness

- [ ] CHK006 Is the conformal score (absolute error normalized by predicted spread, with a floor) specified precisely enough that two implementers compute identical quantiles? [Clarity, Spec §FR-010, §Assumptions "Calibration score"]
- [ ] CHK007 Is the finite-sample quantile rule (`ceil((n + 1)(1 - alpha))`-th smallest score) a requirement, or only a plan decision in research R8? [Gap, Spec §FR-010]
- [ ] CHK008 Are the exchangeability conditions of the coverage guarantee stated: calibration and test bodies from the same generator, the same per-cell view subset rule, and the same noise draw process? [Completeness, Spec §FR-010, §FR-005, §FR-012]
- [ ] CHK009 Is the 87 to 93% band consistent with the calibration and test set sizes (2,000 each), so that a correct implementation cannot fail SC-002 by sampling chance alone? [Consistency, Spec §SC-002, §Assumptions "Tolerance band", §FR-011]
- [ ] CHK010 Is the treatment of flagged or skipped bodies in the calibration set specified (excluded before the quantile; counted in `n_cal` or not)? [Gap, Spec §Edge Cases, §FR-011]
- [ ] CHK011 Is the interval behaviour at the clipping boundary (lower bound 0 cm) defined for coverage counting and for width? [Edge Case, Spec §Edge Cases "lower bound below 0 cm"]
- [ ] CHK012 Is the refusal below the minimum calibration size tied to a stated rationale (the quantile index needs `n + 1 >= 1/alpha`), so that the tiny configuration's lower minimum is justified? [Clarity, Spec §FR-011, Contracts config.md]

## Verdict Computed From Saved Outputs

- [ ] CHK013 Does FR-014 name the exact inputs of the verdict (file and columns) so that the verdict cannot depend on in-memory state? [Clarity, Spec §FR-014, §FR-015, Contracts artifacts.md]
- [ ] CHK014 Is the "median of four ratios" rule unambiguous for ties, for a zero 1-view width, and for a missing cell? [Edge Case, Spec §FR-014]
- [ ] CHK015 Is the outcome for a compared cell outside the band stated consistently between User Story 1 scenario 3 ("comparison invalid") and FR-014 ("KILL otherwise")? [Consistency, Spec §FR-014, §User Story 1]
- [ ] CHK016 Does SC-003 state whether recomputation must match bitwise or within a tolerance, and which saved outputs are the recomputation inputs? [Measurability, Spec §SC-003]
- [ ] CHK017 Are the reported-only rows (height; 2 and 5 degrees; real images) required to be present in the verdict artifact for both PASS and KILL? [Completeness, Spec §FR-014, §FR-020]
- [ ] CHK018 Is it stated that the threshold 0.70 and the circumference set are fixed before the first full run and may not change after a result exists (constitution Principle IV)? [Traceability, Spec §FR-014, Constitution §IV]

## Measurement, View, and Noise Definitions
